git init para crear un nuevo repositorio.
git add para preparar archivos.
git commit -m para guardar cambios.
git status para ver el estado del repositorio.
git push para subir cambios al remoto y git pull para descargar cambios. 
 git branch para manejar ramas.
 git checkout para cambiar entre ramas.
 git merge para fusionar ramas y git log para ver el historial de commits.
